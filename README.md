AWS CI/CD Pipeline Using GitHub Actions and EC2

📌 Project Overview

This project aims to automate the deployment of a static website using AWS EC2 and GitHub Actions.

🎯 Objectives

* Create a static website using HTML.
* Host the website on an AWS EC2 instance.
* Use Nginx as the web server.
* Use GitHub to store and manage the source code.
* Use GitHub Actions to automate deployment.

🛠️ Technologies Used

* HTML
* AWS EC2
* Git and GitHub
* GitHub Actions
* Linux
* Nginx
